# Pollster Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Pollster, a Paper plugin for dialog-based surveys with an in-game editor, MariaDB storage, and a static web report viewer.

**Architecture:** Four Gradle modules. `pollster-api` holds the survey model, condition language, survey flow and report building, with no server dependency except events. `pollster-backend` holds MyBatis/MariaDB storage. `pollster-paper` is the plugin: configs, survey file store, dialogs, commands. `pollster-viewer` is a React/Vite static site. Dialog screens are built as plain `Screen` records first and rendered to Paper dialogs by one renderer, so screen logic is unit-testable without a server.

**Tech Stack:** Java 25, Gradle 9 Kotlin DSL, Paper API 26.3, Incendo Cloud 2.0.1, Configurate YAML 4.2.0, MyBatis 3.5.19, MariaDB Connector/J 3.5.6, plugin-infrastructure 1.0.0-SNAPSHOT, Jackson 2.18.2, JUnit 5.11.4, Mockito 5.23.0, Testcontainers 2.0.x, React 19, Vite 6, Vitest, TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-22-pollster-design.md`

**Reference repo:** the Realty repository. Where a step says "as Realty does", read the named Realty file and follow its structure. Do not copy Realty's domain code.

## Global Constraints

- Paper 26.3+ only: `compileOnly("io.papermc.paper:paper-api:26.3.build.211-stable")`, `api-version: "26.3"` in `paper-plugin.yml`.
- Java toolchain 25; `options.release = 25`; UTF-8; configuration-cache clean (`org.gradle.configuration-cache=true`).
- Group `com.minecraftcitiesnetwork`; base package `com.minecraftcitiesnetwork.pollster`; version from `-PreleaseVersion`, default `1.0.0-SNAPSHOT`.
- Shaded libraries are relocated under `com.minecraftcitiesnetwork.pollster.libraries`, except `com.minecraftcitiesnetwork.pluginInfrastructure`, which is not relocated.
- Every database table is prefixed `pollster_`. The version table is `pollster_schema_version`.
- Nullability: `org.jetbrains:annotations:26.0.2-1`. No Lombok. Records and sealed interfaces where they fit. Explicit `this.` on fields. Comments explain why.
- No static `Bukkit.*` access outside the plugin class. Collaborators receive `Server`, `Logger`, executors through constructors.
- Player-supplied text is inserted into MiniMessage only with `Placeholder.unparsed` (or plugin-infrastructure's `MessageContainer.value`).
- Test names: `subject_condition`.
- `local/` is gitignored and never referenced by committed files.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A survey file broken by hand** (bad YAML, unknown type, duplicate keys) must not stop the plugin or other surveys loading. Expect one clear log line and the survey missing from lists. Test in Task 11.
2. **A stale dialog button** clicked after the survey was closed, reloaded, or deleted, or after the session ended, must not save or crash. Expect "This survey is no longer available." Test in Task 15.
3. **Double Submit** (two clicks or two callbacks racing) must store one response and run rewards once. Tests in Task 8 (database) and Task 15 (flow).
4. **MiniMessage in player input** (`<red>`, `<click:run_command:...>` in text answers, option labels typed by admins, survey names) must render literally wherever it is shown to another player. Tests in Task 15 (review screen) and Task 20 (report screen).
5. **Paste service down or slow** must not freeze the server or lose the report. Expect a chat error with the reason within the timeout, run off the main thread. Test in Task 20.
